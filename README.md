# Инспектор форм 1С

Инспектор форм 1С. Плагин для VS Code и Cursor.

## Описание

Плагин для VS Code и Cursor. Он открывает управляемые формы 1С, которые лежат файлами в выгрузке конфигурации, и позволяет их просматривать и менять.

В инспекторе можно просматривать и менять реквизиты объекта и реквизиты формы, а также их свойства.

Текущий стабильный релиз — [1.23.9.4](https://github.com/Poroot4ik/inspector_form_1C/releases/latest).

## Установка

Скачайте inspector_form_1C-1.23.9.4.vsix. Это можно сделать нажав вверху кнопку Code -> Download ZIP, после скачивания распаковать архив и получить файл с расширением .vsix. Второй вариант скачивания - перейти в ветку релизов, выбрать необходимый релиз, перейти в раздел Assets и скачать файл с расширением .vsix.

В Cursor или VS Code откройте палитру команд View -> Command Palette (Ctrl+Shift+P) и введите команду Extensions: Install from VSIX.... и выполните ее.

Выберите скачанный файл.

Перезагрузите окно View -> Command Palette (Ctrl+Shift+P): Developer: Reload Window.

## Настройка

Настройки инспектора лежат в обычных настройках редактора, не в отдельной панели Cursor.

В VS Code откройте **File → Preferences → Settings** или нажмите `Ctrl+,`. В Cursor то же сочетание `Ctrl+,`. Панель **Cursor Settings** (`Ctrl+Shift+J`) к расширению не относится. В строке поиска введите `1C Form Inspector`.

Пути к выгрузке лучше задавать в настройках рабочей папки (**Workspace**), а не в общих настройках пользователя: у каждого проекта свои каталоги.

### Путь к файлам конфигурации

Инспектору удобнее выгрузка в файлы со структурой [vanessa-bootstrap](https://github.com/vanessa-opensource/vanessa-bootstrap):

```text
проект/
  src/
    cf/
      Configuration.xml
      Catalogs/
      Documents/
    cfe/
      ИмяРасширения/
        Configuration.xml
```

`src/cf` — основная конфигурация. `src/cfe/ИмяРасширения` — отдельная папка на каждое расширение, внутри её собственный `Configuration.xml`. Такие пути уже стоят по умолчанию:

| Настройка | По умолчанию | Что это |
|---|---|---|
| `formInspector.configRoot` | `./src/cf` | Корень основной конфигурации |
| `formInspector.extensionRoot` | `./src/cfe` | Корень расширений |

Относительный путь считается от открытой папки проекта. Можно указать и полный путь, например `C:\...\src\cf`. Пустая настройка или несуществующая папка этот корень отключает: инспектор просто не видит его. После смены пути расширение заново ставить не нужно — новое значение действует при следующем открытии инспектора.

Если выгрузка лежит иначе, поменяйте эти два поля. Например, конфигурация в `C:\...\src\cf`, а расширения в `C:\...\src\cfe`:

```json
{
  "formInspector.configRoot": "C:\\...\\src\\cf",
  "formInspector.extensionRoot": "C:\\...\\src\\cfe"
}
```

### Логирование

Лог — это последовательность действий пользователя в инспекторе. Другие сведения не записываются: ни данные кодовой базы, ни личные данные пользователей.

Логирование по умолчанию выключено. Включайте его, только когда нужно разобрать сбой, и выключайте после этого.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `formInspector.diagnosticLogging.enabled` | выключено | Пишет диагностический лог в файл |
| `formInspector.diagnosticLogging.showOutputPanel` | выключено | Дублирует записи в панель **Output → 1C Form Inspector** |
| `formInspector.diagnosticLogging.location` | `globalStorage` | Куда класть файл |
| `formInspector.diagnosticLogging.maxFileSizeMb` | 5 | Предел размера файла, от 1 до 50 МБ. Дальше старый лог переименовывается в `diagnostic.log.1` |

`globalStorage` хранит лог вне проекта: в Windows это `%APPDATA%\Cursor\User\globalStorage\1c-tools.1c-form-inspector\logs\diagnostic.log` (у VS Code тот же путь внутри каталога VS Code). `workspace` пишет `.cursor-logs/diagnostic.log` в корень открытой папки.

Команды лога открываются через **View → Command Palette** (`Ctrl+Shift+P`):

- **1С: Открыть диагностический лог**
- **1С: Сохранить диагностический лог…**
- **1С: Очистить диагностический лог**

Порядок такой: включить запись, повторить действие, сохранить файл командой и отправить его. Потом запись выключить.

## Тестирование

Инспектор проверялся на демобазе **Розница 2.3**. Формат XML выгрузки — `version="2.20"`, режим совместимости платформы 8.3.24, совместимость расширений 8.3.27. Файлы форм — UTF-8, управляемая форма с корнем `<Form>` и пространством имён `http://v8.1c.ru/8.3/xcf/logform`.

## Ограничения

- Инспектор открывается только из каталогов `formInspector.configRoot` и `formInspector.extensionRoot`. Файл или папка вне этих корней панель не открывает, даже если пункт меню виден.
- Нужна выгрузка конфигурации в файлы: `Catalogs/Имя/Forms/ИмяФормы/Ext/Form.xml`. Бинарный `.cf`, база и проект EDT (файлы `.mdo` и `Form.form`) не подходят.
- Внешние обработки и отчёты (`src/epf`, `src/erf`) сами по себе в область инспектора не входят.
- Обычные формы (`Form.bin`) в превью не показываются. Объект при этом открыть можно.
- Превью строится по XML и показывает схему формы. Это не окно 1С у пользователя и не живой конфигуратор.

### Временные ограничения

- Тщательно проверены формы только справочников и документов. Формы других объектов метаданных открываются, но в них могут быть ошибки.
- Форма динамического списка может отображаться некорректно: полноценный показ таких форм ещё не сделан. Также не полностью сделаны табличные части и динамические списки, размещённые на форме, и их события.
- Перетаскивание реквизита, чтобы добавить элемент на форму, работает только на вкладке **Элементы**. На область **Предварительный просмотр** перетаскивание пока не сделано.
- Новые реквизиты можно создавать, а свойства существующих менять. Это не проверено целиком, поэтому возможны ошибки. На вкладке **Свойства** в разделе **Прочее** собраны свойства, которые ещё не проверены или в инспекторе не используются.
- Тип реквизита, в том числе составной, можно задать и изменить. Это тоже не проверено целиком, поэтому возможны ошибки.
- На вкладке **Параметры** параметры формы видны: их можно добавить, переименовать и удалить. Свойства параметров и дальнейшая работа с ними не доведены.
- Глобальные команды в области предварительного просмотра отображаются некорректно.

## Использование

### Выбор объекта конфигурации из дерева файлов

Откройте в редакторе папку проекта, внутри которой лежит выгрузка. В проводнике щёлкните правой кнопкой папку объекта, например `src/cf/Catalogs/Номенклатура`, или файл `Form.xml`, и выберите **1С: Инспектор форм**. Та же команда есть в палитре: **View → Command Palette** (`Ctrl+Shift+P`). Обычный щелчок по папке инспектор не открывает.

Если вызвать команду на корне выгрузки или на папке вида (`Catalogs`, `Documents`), откроется выбор объекта. Папка объекта без управляемых форм тоже открывается: видны реквизиты объекта, а у превью формы будет пустое состояние.

### Выбор объекта конфигурации для просмотра в инспекторе

На вкладке **Формы** находится поле для выбора объекта конфигурации. Нажатие на него открывает меню выбора объекта. В поле ввода можно ввести название объекта, затем выбрать его для просмотра.

## Интерфейс

### Области

Инспектор состоит из вкладок. Сразу после открытия окно разделено на четыре зоны:

1. Вкладки **Формы**, **Свойства**, **События**.
2. Вкладки **Реквизиты**, **Команды**, **Параметры**.
3. Вкладка **Элементы**.
4. Вкладка **Предварительный просмотр**.

Можно создать новую область кнопкой **Новая область** или перетащить существующую вкладку в другую область. После перезапуска инспектора расположение вкладок возвращается к исходному.

### Цветовая схема

Часть вкладок и стрелки перехода окрашены одинаково: по цвету видно, куда ведёт связь.

На вкладке **Свойства** у полей, которые ссылаются на реквизит, команду или процедуру, справа стоит стрелка. Если на форме выбрана кнопка с командой формы, у свойства **Имя команды** стрелка зелёная. Нажатие открывает вкладку **Команды** и выделяет эту команду. У стандартной команды такой стрелки нет. Если выбрана сама команда, у свойства **Действие** стрелка синяя: нажатие открывает модуль формы и переходит к её процедуре. У свойства **Путь к данным** стрелка фиолетовая и выделяет связанный реквизит на вкладке **Реквизиты**. На вкладке **События** отдельной стрелки к реквизитам и командам нет: синяя стрелка там тоже открывает процедуру в модуле, а жёлтая молния показывает, что обработчик уже есть.

Цвета распределены так:

- **Жёлтый** — вкладка **События**.
- **Фиолетовый** — вкладка **Реквизиты**.
- **Зелёный** — вкладка **Команды**.
- **Оранжевый** — вкладка **Параметры**.
- **Синий** — модуль формы.

Вкладки **Формы**, **Свойства**, **Элементы** и **Предварительный просмотр** оставлены без своего цвета: это общие вкладки формы.

### Иконки

У реквизитов и у элементов формы, связанных с ними, стоят иконки типов. Справочник — стопка книг, строка — буква **T**, число — **00**, булево — флажок. У составного типа серый прямоугольник с многоточием. Если для типа иконки ещё нет, остаётся серый прямоугольник без знака. В конфигураторе такие реквизиты показаны прямоугольниками разного цвета.

Иконки типов видны в дереве реквизитов объекта и формы на вкладке **Реквизиты** и в дереве элементов на вкладке **Элементы**.

Иконки команд сделаны похожими на картинки 1С и могут немного отличаться.

### Вкладки

Интерфейс близок к редактору управляемой формы в конфигураторе.

#### Формы, Свойства, События

Вкладка **Формы** показывает все формы объекта. Обычные формы в списке серые, с ними нельзя работать как с управляемыми: дерево элементов и превью для них не строятся. Управляемую форму можно выбрать и смотреть. Сверху, рядом с кнопкой **Новая область**, есть поле с именем текущей формы. Нажатие на него открывает список управляемых форм этого объекта, и форму можно сменить.

Вкладка свойств конфигуратора здесь разделена на две: **Свойства** и **События**. Они стоят рядом с вкладкой **Формы**. На вкладке **Свойства** видны свойства выбранного элемента формы, а также реквизита формы или реквизита объекта.

На вкладке **События** показаны события выбранного элемента формы. Жёлтая молния означает, что обработчик уже есть в модуле формы. Кнопки строки появляются, когда на неё наводят указатель. Синяя стрелка открывает существующую процедуру в модуле. Серая стрелка создаёт новую процедуру и открывает модуль. Красный крестик после подтверждения удаляет процедуру из модуля формы.

#### Реквизиты

На вкладке **Реквизиты** дерево показывает либо реквизиты объекта, либо реквизиты формы. Над деревом переключатель: имя основного реквизита (обычно **Объект**) и **Форма**. Если у формы нет основного реквизита-объекта, остаётся только **Форма**.

Кнопка **Добавить реквизит** создаёт реквизит в той части, которая сейчас выбрана: объекта или формы.

Если выделить реквизит, открывается вкладка **Свойства** со свойствами этого реквизита.

У реквизита типа ссылки на справочник или документ слева стоит **+**, если тип один. Нажатие раскрывает вложенные реквизиты; после раскрытия знак меняется на **−**. Вложенные реквизиты можно смотреть и перетаскивать на вкладку **Элементы** так же, как обычные. У составного типа плюса нет, даже если среди типов есть такая ссылка.

Справа от имени серым написан тип, например «Строка» или «СправочникСсылка.Ассортимент».

#### Команды, Параметры

На вкладке **Команды** — пользовательские команды и команды формы. На вкладке **Параметры** — параметры формы.

#### Элементы

Вкладка **Элементы** стоит справа и растянута на всю высоту окна: так удобнее смотреть дерево элементов формы. Жёлтая молния стоит в дереве справа от элемента, если у него есть события в модуле. Нажатие на неё открывает вкладку **События** этого элемента.

Если выделить элемент в дереве, открывается вкладка **Свойства** со свойствами этого элемента.

Порядок строк меняется перетаскиванием: захватите элемент левой кнопкой и перетащите его в нужное место дерева. Над группой она обводится синим пунктиром — элемент попадёт внутрь. Между соседними строками появляется синяя полоска: она показывает, куда встанет элемент.

Реквизит объекта или формы можно перетащить из дерева на вкладке **Реквизиты** в дерево на вкладке **Элементы**. В месте отпускания создаётся новый элемент формы.

#### Предварительный просмотр

Вкладка **Предварительный просмотр** показывает форму так же, как предварительный просмотр в конфигураторе.

### Всплывающее меню

Правый щелчок по строке открывает меню. Оно есть не на каждой вкладке: пункты зависят от вкладки и от выбранного элемента.

Если на вкладке **Элементы** щёлкнуть элемент формы, в меню можно переименовать или удалить его, открыть его события, а также добавить группу, поле или таблицу. Новый элемент появляется внутри выделенной группы. Если выделен обычный элемент, а не группа, новый встаёт сразу под ним. Корень **Форма** переименовать и удалить нельзя.
