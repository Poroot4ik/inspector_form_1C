# inspector_form_1C

Инспектор форм 1С. Плагин для VS Code и Cursor.

## Установка

Скачайте inspector_form_1C-1.23.9.2.vsix. Это можно сделать нажав вверху кнопку Code -> Download ZIP, после скачивания распаковать архив и получить файл с расширением .vsix. Второй вариант скачивания - перейти в ветку релизов, выбрать необходимый релиз, перейти в раздел Assets и скачать файл с расширением .vsix.

В Cursor или VS Code откройте палитру команд View -> Command Palette (Ctrl+Shift+P) и введите команду Extensions: Install from VSIX.... и выполните ее.

Выберите скачанный файл.

Перезагрузите окно View -> Command Palette (Ctrl+Shift+P): Developer: Reload Window.
