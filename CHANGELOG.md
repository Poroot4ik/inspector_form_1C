# Changelog

Все заметные изменения инспектора записываются в этот файл.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Заметные версии нумеруются как MAJOR.MINOR.PATCH.
Публикуемый файл расширения добавляет номер сборки, например `1.23.9.2`.

## [Unreleased]

## [1.23.9.2] - 2026-10-17

### Added

- Публичная сборка расширения для Cursor и VS Code.

## [1.23.0] - 2026-09-26

### Added

- Заголовок обычной группы рисуется зелёным и крупнее подписи поля. Сильное выделение — полоса слева от содержимого. Свертываемая группа подчёркивает заголовок или показывает значок. Всплывающая группа по умолчанию закрыта и раскрывается на форме.
- Горизонтальное положение командной панели: Лево, Центр или Право прижимает кнопки в ленте. Если свойство не задано, кнопки остаются слева.

### Changed

- Пустая обычная группа не занимает место в превью. В дереве элементов группа остаётся.
- Группа из картинок и полей фиксированной ширины сжимается по содержимому: не делит горизонтальный ряд пополам и не растягивается на всю колонку.
- Скрытый заголовок группы и отсутствие «Отображения» не рисуют серую рамку.

### Fixed

- У флажка с положением «Авто» галочка стоит справа от заголовка. Если заголовок поля стоит справа от поля, в конце подписи нет двоеточия.
- Красный пунктир следует автоотметке незаполненного: Да, Нет или Авто.
- Декорация-картинка по высоте совпадает с однострочным полем.
- При прокрутке дерева элементов видны строки ниже первого экрана.
- Лента таблицы занимает всю ширину, «Ещё» стоит у правого края. Панель без источника сжимается по своим кнопкам.

## [1.22.0] - 2026-09-16

### Added

- Высота поля ввода: многострочный реквизит и «Растягивать по вертикали» дают 1, 3 или 5 строк. Поле не растягивается в остаток родителя.
- В режиме выбора из списка поле рисуется как комбо независимо от типа реквизита.
- Если у кнопки общей команды пустые заголовок, картинка и отображение, они берутся из этой команды.
- У корня «Форма» видны свойства и состав команд. Набор стандартных кнопок зависит от основного реквизита: справочник, документ, список или форма без объекта.
- Соседние колонки в горизонтальной группе делят ряд по числу вложенных колонок, а не пополам.

### Changed

- Положение командной панели «Нет» скрывает панель, «Низ» рисует её под элементами.
- «Справка» и «Изменить форму» стоят на ленте справа от «Ещё».
- «Записать и закрыть», «Записать» и «Провести» на ленте по умолчанию только с текстом, в «Ещё» — с картинкой и текстом.
- Подпись и картинка подменю берутся из свойства «Отображение», как у обычной кнопки.
- У группы с источником «Форма» в «Ещё» появляется набор стандартных команд объекта.
- У отдельной командной панели без источника кнопка «Ещё» появляется, только когда свои кнопки не влезают.

### Fixed

- Высокое поле с заголовком сверху занимает ширину слота, а не ширину текста заголовка.
- В свойствах общей команды показывается её имя, а не список команд формы.
- Стандартные команды формы выбираются по основному реквизиту, а не только по виду справочника.

## [1.21.0] - 2026-08-30

### Added

- В свойствах таблицы есть состав команд. На ленте и в «Ещё» у команд есть подписи.
- Картинка и заголовок кнопки или декорации берутся с элемента или с его команды, по свойству «Отображение».
- При «Текст и картинка» картинка на форме стоит слева или справа. В меню «Ещё» картинка всегда слева.
- Положение в командной панели: Авто у команды формы ставит её на ленту и в «Ещё», у стандартной команды — только в «Ещё».
- Кнопка в шапке копирует путь элемента.
- Инспектор открывается из настраиваемых каталогов конфигурации и расширений.

### Changed

- В «Ещё» явные кнопки показывают текст и картинку. На вкладке команд раздел называется «Команды формы».
- Группа кнопок без автозаполнения командной панели рисуется компактным сегментом.
- Явная ширина обычной группы ограничивает её размер. Поля с максимальной шириной не разъезжаются в горизонтальном ряду.
- У поля надписи область значения пустая.

### Fixed

- Явное отображение кнопки важнее отображения команды. «Авто» без картинки показывает заголовок.
- Лента таблицы не схлопывается в одну кнопку. В «Ещё» остаётся набор команд табличной части.
- Пустая командная панель без источника и без кнопок не рисуется.

## [1.20.0] - 2026-08-23

### Added

- Объект без управляемых форм открывается по своей папке. На вкладке «Реквизиты» можно смотреть и править реквизиты объекта.
- На вкладке «Формы» объект можно сменить. Загружаются формы выбранного объекта.
- Клик по объекту в списке форм показывает дерево его реквизитов.
- Иконки в дереве зависят от типа реквизита или элемента.

### Fixed

- Командная панель учитывает кнопки внутри подменю и группы кнопок.
- В списке смены объекта есть виды метаданных, у которых бывают формы. Перечисления включены, константы нет.

## [1.19.0] - 2026-08-19

### Added

- В превью учитываются цвет текста, фона и заголовка элемента.
- Картинка на закладке страницы есть только если она задана у страницы. Боковые закладки заполняются картинкой. Горизонтальные закладки остаются компактными.

### Changed

- Разбор формы не пересобирается целиком на каждый клик. Смена страницы и выделение элемента не сбрасывают картинки и активную вкладку.

### Fixed

- Копирование имени срабатывает с первого клика.
- Рамка выделения не пропадает после клика и смены страницы.
- Неограниченная строка растягивается по правилу «Авто». У ссылок есть верхняя граница ширины. Длина наименования и кода берётся с объекта.
- Кнопки поля «…» и стрелки регулирования следуют свойствам элемента.
- Короткий заголовок остаётся слева в колонке заголовков.
- Ряд полей сжимается по заданной ширине до переноса заголовка.

## [1.18.0] - 2026-08-10

### Added

- Пустая командная панель с выключенным автозаполнением и без своих кнопок не показывается. У динамического списка на месте «Добавить» стоит строка поиска. У таблицы есть набор кнопок автозаполнения.

### Changed

- Рамка выделения быстрее появляется и обводит группы, таблицы и кнопки командной панели.

### Fixed

- Значение автозаполнения командной панели читается и записывается в XML.
- Внешняя командная панель находит связанную таблицу по источнику команд.
- Рамка выделения кнопки не обрезается контейнером панели.

## [1.17.0] - 2026-08-09

### Added

- Ширина поля в превью считается по ширине, растягиванию, максимальной ширине и типу реквизита.
- В превью есть переключатель и радиокнопки. Список выбора редактируется в свойствах.

### Changed

- Замер горизонтального ряда идёт по компактной ширине. Растягивание забирает остаток, максимальная ширина ограничивает поле даже при явной ширине.
- При выключенном растягивании заголовок остаётся слева, если заголовок и поле влезают в родителя. Иначе заголовок переносится над полем.
- Явная ширина надписи задаёт её слот. Соседи с растягиванием её не сжимают.

### Fixed

- Короткое поле больше не остаётся с заголовком сверху, если колонка группы достаточно широкая.
- Поле с растягиванием не схлопывается, надпись не теряет двоеточие.
- Поля и группы в колонках не наезжают друг на друга.
- Заголовок и поле не пересекаются.
- Для строки правило «Авто» у растягивания зависит от длины типа.

## [1.16.0] - 2026-07-31

### Added

- У реквизита-ссылки в дереве «Реквизиты» можно раскрыть поля целевого объекта. Перетаскивание на форму задаёт полный путь к данным.
- В диалоге типа можно указать несколько типов сразу.

### Changed

- Имя элемента, созданного из вложенного пути, собирается из сегментов этого пути.

### Fixed

- Если у элемента нет своего заголовка, для вложенного пути показывается синоним реквизита.
- Переход по пути к данным раскрывает родителя и выделяет строку.
- В дереве стандартные имена и типы показываются по-русски.
- Раскрытый список вложенных реквизитов не уезжает при выборе самой ссылки.
- Поле даты в превью шире и показывает календарь справа. У таблицы шапка колонок остаётся на месте при прокрутке.

## [1.15.0] - 2026-07-30

### Added

- Группа «горизонтально, если возможно» переключается между горизонтальной и вертикальной раскладкой по ширине родителя и содержимому.
- Подписи полей выравниваются в колонку. У группы есть растягивание по высоте и рамка.
- Содержимое группы прижимается к углу по свойствам выравнивания.

### Changed

- Расширение ставится файлом из GitHub Releases.

### Fixed

- Без явной группировки группа ведёт себя как вертикальная.
- Поля не вылезают за границы горизонтальных колонок.
- При выключенном горизонтальном растягивании поле остаётся компактным.
- Заголовки и надписи не сжимаются соседним полем ввода.
- Растягивание по вертикали не ломает равные доли в строго горизонтальной группе.

## [1.14.0] - 2026-07-29

### Added

- Свойства элемента сгруппированы: «Основные», «Использование», «Оформление» и «Расположение». Так же сгруппированы свойства реквизитов.
- В панели есть свойства формы, которые раньше были скрыты. Пока значение не задано в XML, оно неактивно.
- Подменю открывается в превью. Свойства и название вида локализованы.
- Стрелка у пути к данным переходит к реквизиту на вкладке «Реквизиты».

### Fixed

- Надпись с гиперссылкой рисуется как ссылка.
- Поле даты показывает маску и значок календаря.
- Названия типов и значений свойств локализованы. В XML токены не меняются.
- Пользовательская видимость «Ложь» в превью выглядит как недоступное поле.
- Значения по умолчанию видимости, доступности и «только просмотр» совпадают с обычными значениями формы.
- Клик в превью открывает вкладку «Свойства».

## [1.12.0] - 2026-07-12

### Added

- Видимость, доступность и «только просмотр» влияют на превью. Невидимое скрыто. Недоступное гаснет вместе с заголовком. «Только просмотр» делает серым поле ввода.
- У реквизитов есть «Проверка заполнения». Обязательное поле подчёркивается красным пунктиром.
- В панели одно поле «Тип» у реквизита и одно поле «Вид» у элемента.
- У группы одно поле «Группировка».
- XML выравнивается после каждого изменения.
- Диагностический лог включается отдельно и записывает действия в инспекторе.

### Fixed

- Группа без отображения сохраняется допустимым тегом обычной группы, а не неизвестным тегом.
- У новой группы записывается группировка и не двоится с полем «Группа».
- «Доступность» и «только просмотр» применяются в превью.
- Новый реквизит попадает в свою секцию XML, свойства идут в обычном порядке.
- При смене типа в XML не копятся пустые строки.

## [1.11.0] - 2026-07-10

### Added

- Значения свойств с фиксированным списком выбираются из локализованного списка.
- Свойство, записанное в XML и равное значению по умолчанию, показывается серым.
- Реквизит типа «Булево» при переносе на форму становится флажком.
- Контекстное меню дерева остаётся в пределах окна.

### Fixed

- В панели свойств реквизита остаётся одно поле типа.
- Заголовок декорации-надписи виден в превью, если он заполнен.
- При положении заголовка «Нет» скрывается заголовок поля, а не соседние надписи.
- Контекстное меню не уходит за нижний край окна.

## [1.10.0] - 2026-07-10

### Added

- На вкладке «Реквизиты» отдельные секции «Объект» и «Форма».
- Кнопка «Добавить реквизит» создаёт реквизит в активной секции.
- Свойства реквизита объекта читаются из XML объекта.
- Длинный список реквизитов прокручивается без зависания.

### Fixed

- Дерево реквизитов не сбрасывает прокрутку при выборе строки в той же секции.
- При смене формы дерево реквизитов обновляется.
- Переход по пути к данным открывает нужную секцию.

## [1.9.0] - 2026-07-09

### Added

- Инспектор читает реквизиты и табличные части объекта из XML объекта, вместе с типом и синонимом.
- В список входят стандартные реквизиты объекта.
- Реквизит объекта можно создать, переименовать, удалить и сменить ему тип. Изменения записываются обратно в XML.

## [1.8.0] - 2026-07-09

### Added

- Тип реквизита и параметра выбирается в отдельном окне, с группами и поиском.
- Доступны примитивные типы и ссылки на объекты открытой конфигурации.
- Выбранный тип сохраняется в XML формы.

## [1.3.0] - 2026-07-09

### Added

- На вкладке «Команды» видны стандартные команды, которые уже стоят на форме.

### Changed

- Стандартные команды в панели свойств только для чтения.
- Элемент со стандартной командой в дереве выделяется цветом.

## [1.2.0] - 2026-07-09

### Added

- У команды есть переход к её кнопке на форме: дерево раскрывается до этой кнопки.

### Fixed

- Исправлен белый экран при запуске.
- Снова показывается уведомление при копировании имени.

## [1.1.0] - 2026-07-09

### Added

- Из свойств можно перейти к процедуре модуля формы.
- Команду можно выбрать из списка.
- Имена команд показываются без служебного префикса.
- Запись XML сохраняет структуру файла.
